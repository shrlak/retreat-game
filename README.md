# 빛의 원정대

수련회·교회 모임에서 각자 휴대폰으로 함께하는 **숨은 역할 추리 게임**입니다.
빛의 일꾼들은 사명 5개 중 3개를 이루려 하고, 유혹의 무리는 몰래 사명을 방해합니다.
규칙 구조는 널리 알려진 팀 원정 추리 보드게임과 같지만, 이름·그림·문구는 모두 새로 만든 것입니다.

**바로 하기:** https://shrlak.github.io/retreat-game/

## 하는 법

1. 한 사람이 이름을 쓰고 **방 만들기**를 누르면 방장이 되고, 5자리 방 코드가 나옵니다.
2. 다른 사람들은 각자 폰에서 이름과 **방 코드**를 넣고 참가합니다. (5~10명)
3. 방장이 인원에 맞게 역할과 확장 규칙을 고릅니다. 선지자를 빼면 파수꾼과 정탐꾼도 함께 빠지고, 선지자가 있으면 정탐꾼은 늘 들어갑니다(대기실에 🔒 표시). 고른 역할이 인원에 맞지 않으면(예: 5~6명에 랜슬롯까지 켜면 유혹의 무리 자리가 모자람) 게임 시작 버튼 바로 위에 이유가 나옵니다.
4. 모두 **준비 완료**를 누르면 방장이 **게임 시작**을 누릅니다. 역할은 무작위로 나뉩니다.
5. 내 역할 카드를 확인한 뒤, 조장이 원정대를 제안 → 모두 찬성/반대 투표 → 뽑힌 원정대가 몰래 축복/방해 카드를 냅니다.
6. 사명 3번 성공이면 빛의 일꾼들, 3번 방해면 유혹의 무리가 이깁니다. 빛이 3번 성공해도 마지막에 정탐꾼이 선지자를 찾아내면 유혹의 무리가 이깁니다. 한 사명에서 원정대가 5번 연속 반대되어도 유혹의 무리가 이깁니다.

첫 화면에서 **한국어 / English**를 고를 수 있어요. 고른 언어로 모든 화면·역할·안내·서버 메시지가 나오고, 디자인과 애니메이션은 똑같습니다.

폰이 잠겨도 같은 폰으로 다시 열면 그대로 이어집니다. 폰을 바꿨다면 방장이 **다시 입장 허용**을 눌러야 같은 이름으로 들어올 수 있습니다 (다른 사람이 이름만 써서 자리를 가져가 역할을 보는 것을 막기 위해서입니다). 방장이 1분 넘게 접속하지 않으면 다른 사람이 **방장 맡기**를 할 수 있습니다.

## 역할

| 역할 | 편 | 하는 일 |
|---|---|---|
| 선지자 | 빛 | 유혹의 무리를 알고 있음 (양의 탈을 쓴 늑대는 안 보임) |
| 파수꾼 | 빛 | 선지자 후보 둘(선지자, 거짓 선지자)이 보임 |
| 빛의 일꾼 | 빛 | 정보 없음 |
| 정탐꾼 | 유혹 | 마지막에 선지자를 지목 |
| 거짓 선지자 | 유혹 | 파수꾼에게 선지자처럼 보임 |
| 양의 탈을 쓴 늑대 | 유혹 | 선지자에게도 안 보임 |
| 방황하는 자 | 유혹 | 동료를 모르고 동료도 모름 |
| 유혹하는 자 | 유혹 | 동료를 알고 있음 |

### 확장 규칙 (방장이 켜고 끔)

- **등불**: 2·3·4번째 사명 뒤에 등불을 가진 사람이 한 명의 편을 몰래 확인하고 등불을 넘깁니다.
- **갈림길의 순례자 (선한 랜슬롯, Good Lancelot) / 갈림길의 그림자 (악한 랜슬롯, Evil Lancelot)**: 편이 바뀔 수 있는 두 역할. 공식 룰북의 세 가지 변형을 그대로 따릅니다. 첫날 밤에 그림자는 눈을 감고 엄지만 내밀어서, 유혹의 무리(방황하는 자 제외)는 그림자를 알지만 그림자는 동료를 모릅니다.
  - 변형 1: 갈림길 카드 5장(그대로 3, 편이 바뀜 2) 중 3·4·5번째 사명이 시작될 때 한 장씩 뒤집습니다. 두 랜슬롯은 서로 모릅니다.
  - 변형 2: 갈림길 카드 7장(그대로 5, 편이 바뀜 2) 중 5장을 처음부터 사명마다 한 장씩 펼쳐 둡니다. 그 사명이 시작될 때 편이 바뀌고, 랜슬롯은 지금 편대로만 카드를 냅니다(유혹 편이면 방해, 빛 편이면 축복).
  - 변형 3: 편이 바뀌지 않고, 두 랜슬롯이 서로를 압니다.
- **말씀 두루마리 (Excalibur)**: 조장이 원정대 중 한 명에게 두루마리를 줍니다. 카드가 다 나온 뒤 그 사람은 다른 원정대원 카드 하나를 뒤집을 수 있고, 원래 카드는 혼자만 압니다.
- **밸런스 모드**: 5인·7인의 원정대 인원 순서를 바꿉니다.

## 구조

- **화면**: 빌드 없는 정적 사이트(HTML/CSS/바닐라 JS), GitHub Pages에서 제공
- **서버**: Supabase Edge Function `mist-game` 하나가 모든 규칙을 판정 (`server/handler.js` + `server/engine.js`)
- **저장**: Postgres 테이블 `public.mist_rooms` (RLS 켜짐, 함수만 접근)
- **실시간**: Supabase Realtime 채널 `mist:<방코드>` + 4초마다 확인
- **두 언어**: 이름·문구는 `web/config.js`의 `THEME`(한국어)와 `THEME.i18n.en`(영어), 서버 메시지는 `server/messages.js`에 두 언어로 있음
- **동시 화면 전환**: 서버가 단계가 바뀐 시각(`phaseStartedAt`)을 주고, 각 폰이 서버 시계에 맞춰 같은 순간에 전환 애니메이션을 시작

```
index.html          페이지 (모든 스크립트를 불러옴)
site.webmanifest    홈 화면 아이콘
web/config.js       이름·문구·역할 그림 경로 (이름은 여기서만 바꿈)
web/net.js          서버 호출, 실시간, 서버 시계
web/app.js          연결부
web/dev-ui.js       단순한 대체 화면 (?dev=1)
ui/                 실제 게임 화면과 애니메이션 (ui/src → ui/build.js → ui/ui.js)
guide/guide.js      규칙 안내, 역할 팁, 진행자 가이드
assets/             그림 (역할 카드, 배경, 지도, 아이콘, 로고)
server/             규칙 엔진, 서버 함수
tests/              테스트
CONTRACT.md         모듈 사이 약속 (API, 화면이 받는 데이터 모양)
HANDOFF.md          인수인계: 지금 상태, 다음 할 일
CLAUDE.md           Claude Code용 작업 안내
```

## 로컬에서 실행·테스트

```bash
# 화면 띄우기 (실제 서버에 연결됨)
python3 -m http.server 8000   # → http://localhost:8000/

# 규칙 엔진·서버 로직 테스트 (Node 20+)
node --test tests/*.test.mjs

# 실제 서버에 봇으로 전체 게임 돌리기 (브라우저에서 열기)
# https://shrlak.github.io/retreat-game/tests/e2e.html?from=5&to=10&games=2
```

## 배포

- **화면**: `main`에 push하면 GitHub Pages가 자동 배포합니다.
- **서버 함수**: Supabase CLI로 `server/`를 `mist-game`으로 배포 (`verify_jwt` 끔, 함수가 자체 토큰으로 확인).
  ```bash
  supabase functions deploy mist-game --project-ref datihyxdmpshreyifvzn --no-verify-jwt
  ```
  (지금은 `index.ts`가 jsDelivr에 고정된 커밋의 `server/handler.js`를 불러오는 방식으로 배포되어 있습니다. 자세한 내용은 HANDOFF.md)

이어서 작업하려면 [HANDOFF.md](HANDOFF.md)와 [CLAUDE.md](CLAUDE.md)를 먼저 읽어 주세요.
