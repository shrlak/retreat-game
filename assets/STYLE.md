# 빛의 원정대 — 아트 스타일 가이드

교회 수련회 밤과 새벽을 닮은 따뜻한 동화책 스타일. 게임 규칙은 원작과 같고, 그림만 새로 만든 오리지널 아트입니다. 원작 게임의 그림은 하나도 쓰지 않습니다.

## 분위기: 성경적이고 화려하게
- 성경 시대 배경: 유대 언덕, 올리브 나무, 돌집 마을, 성벽, 목자의 들판, 양, 별 하나가 빛나는 밤하늘, 구름 사이 빛줄기.
- 장식: 스테인드글라스 아치, 금박 테두리, 두루마리 이름판, 올리브 가지, 토기 등잔, 비둘기.
- **빛의 일꾼들(good)**: 새벽빛, 금색, 크림색 양피지, 하늘색, 초원.
- **유혹의 무리(evil)**: 보랏빛 해질녘, 남색 밤, 라일락. 장난스러운 눈빛, 가면, 그림자, 달. 무섭지 않고 귀엽게 얄미운 느낌.
- 폭력적 이미지 금지(무기, 피, 해골 없음). 정탐꾼은 망원경, 늑대는 양털 옷을 입은 웃긴 늑대, 유혹하는 자는 사과를 내미는 귀여운 뱀.
- 그림 안에 글자를 넣지 않습니다. 역할 이름과 문구는 UI가 렌더링합니다. (로고만 예외: 한글 제목을 손으로 그린 패스로 넣음.)

## 애니메이션과 성능 (렉 없이)
- 움직임은 `transform`과 `opacity`만 애니메이션합니다(GPU 합성). 그라디언트, 필터, 패스 모양은 움직이지 않습니다.
- SVG 필터(blur, drop-shadow) 사용 안 함. 빛 번짐은 radialGradient.
- 파일당 움직이는 요소는 대략 10개 이하.
- 애니메이션 클래스를 `transform=""` 속성이 있는 요소에 직접 붙이지 않습니다(CSS가 위치를 덮어씀). `<g transform><g class>` 로 감쌉니다.
- 모든 애니메이션은 `prefers-reduced-motion: reduce` 에서 멈춥니다.
- 역할 카드에는 금빛 반짝임(`.shim`)이 7초마다 한 번 카드 위를 지나갑니다.
- UI 팁: 화면 밖이나 숨겨진 카드는 `<img>`를 DOM에서 빼거나 `display:none` 으로 두면 애니메이션 비용이 0이 됩니다. 카드 20장 이상을 동시에 띄울 땐 `<img>`로 쓰는 편이 인라인 SVG보다 가볍습니다.

## 형태 규칙
- 평면(flat) 벡터 + 부드러운 그라디언트. 외곽선 대신 색 면과 밝은 하이라이트.
- 모서리는 둥글게, 선 끝은 `stroke-linecap="round"`.
- 파일 안의 모든 id는 파일마다 고유한 접두사를 붙입니다(여러 SVG를 한 페이지에 인라인해도 충돌 없음).
- 내장 애니메이션 클래스(`_src/lib.py`): 불꽃 흔들림(`.fl`), 별 반짝임(`.tw .tw2 .tw3`), 빛 맥동(`.glow`), 안개(`.drift`), 둥실(`.bob`), 금빛 훑기(`.shim`), 천천히 회전(`.spin`). `<img>`로 넣어도 동작합니다.

## 크기
- 역할 카드 / 카드 뒷면: viewBox `0 0 600 840` (2.5:3.5). 그림 창 x30 y30 w540 h650 (위쪽은 스테인드글라스 아치), **이름판 빈칸 x46 y700 w508 h104** (UI가 이름을 여기에 겹쳐 쓰면 됨: 카드 너비 기준 left 7.7%, top 83.3%, width 84.7%, height 12.4%).
- 토큰, 투표 카드, 조장, 등불, 팀 문장, 아바타: `0 0 200 200`.
- 아이콘: `0 0 24 24`, `stroke="currentColor"` 이라 CSS `color`로 색을 바꿈.
- 배경: 세로 `0 0 600 1300`, `preserveAspectRatio="xMidYMid slice"` → CSS `background-size: cover` 권장.
- 패턴: `bg-pattern.svg` 타일(남색 채움), `bg-pattern-overlay.svg` 투명 타일.

## 생성
`python3 _src/build_*.py` 로 다시 만들 수 있습니다. 파일 목록과 경로는 `manifest.json`.
