# 규칙 체크리스트 (원작 아발론 기준)

출처: 원작 레지스탕스 아발론 규칙서 기준 (확장은 rulespal.com 룰북 전사본, 출판사 PDF 아님). 사용자가 준 나무위키 문서는 이 환경에서 보안 확인(Cloudflare) 때문에 열지 못했음 → 나무위키 전용 항목은 열람 후 보강 필요.
열: **ID** / 규칙 / 엔진 구현 / 자동 테스트.
상태: ✅ 구현+테스트, ⚠️ 구현됐지만 원작과 다름/의심, ❌ 미구현.

## L. 랜슬롯 (공식 룰북: rulespal.com의 Avalon / Avalon Big Box 룰북 전사본 기준)
공통: 선 랜슬롯 1명 + 악 랜슬롯 1명이 선 1자리·악 1자리를 대신함(악 인원수 A2는 그대로). 7명 이상 권장.
| ID | 규칙 |
|---|---|
| L0 | **기본 모드**: 두 랜슬롯이 서로를 알고 서로의 진영도 앎. 충성 카드 없음. 원정 카드는 일반 규칙(선=성공만, 악=선택) |
| L1 | **변형 1/2 공통 밤**: 두 랜슬롯은 서로 모름. 악 랜슬롯은 다른 악에게 보이지만(엄지), 자기는 다른 악을 못 봄 |
| L2 | 오베론은 악 랜슬롯도 못 봄 (FAQ 해석) |
| L3 | 멀린이 악 랜슬롯을 보는지: 룰북에 없음 → 구현 결정 필요, 결정대로 테스트 |
| L4 | **변형 1**: 충성 덱 6장(변화없음 4, 진영교체 2). 매 원정 시작 때 1장 공개(1~5번 원정, 총 5장). 교체가 나오면 두 랜슬롯 진영이 비밀리에 바뀜. 0~2번 바뀔 수 있음 |
| L5 | **변형 2**: 충성 덱 7장(변화없음 5, 교체 2) 중 5장을 원정마다 1장씩 미리 공개 배치, 나머지 2장 제외. 해당 원정 시작 때 교체 |
| L6 | 변형 2: 선 랜슬롯은 반드시 성공, 악 랜슬롯은 반드시 실패 카드 (현재 진영 기준) |
| L7 | 진영 교체는 승리 조건·원정 카드 규칙 모두에 적용 (교체 후 현재 진영으로 승패 판정) |
| L8 | 교체된 사실·현재 진영은 두 랜슬롯 본인 말고 아무도 모름 (공개되는 건 뽑힌 충성 카드뿐) |
| L9 | 호수의 여인으로 랜슬롯을 보면 어떤 진영이 보이는지: 룰북에 없음 → 구현 결정 필요 |
| L10 | 암살: 룰북에 별도 규칙 없음 → 현재 진영 기준(추론) |
| L11 | "변형 3"(교체 없음, 서로 앎)은 룰북에 없고 FAQ 해석뿐 → L0과 같음 |

## X. 엑스칼리버 (빅박스)
| ID | 규칙 |
|---|---|
| X1 | 대장이 원정대를 정할 때 원정대원 중 1명에게 줌. 대장 자신에게는 못 줌 |
| X2 | 원정 카드가 모두 제출된 뒤, 공개 전에 보유자가 다른 원정대원 1명을 골라 카드를 바꾸게 할 수 있음 (선택 사항, 자기 자신 불가) |
| X3 | 보유자만 원래 낸 카드를 봄 → 그 사람이 성공/실패 중 뭘 냈는지 보유자만 앎 |
| X4 | 바꾼 뒤 결과 공개는 평소대로 (실패 장수만) |
| X5 | 선 플레이어의 성공 카드가 엑스칼리버로 실패로 바뀔 수 있음 (선은 "성공만 낸다"는 제한은 낼 때만) |
| X6 | 대장이 엑스칼리버를 꼭 줘야 하는지, 사용 여부가 다른 사람에게 공개되는지: 룰북에 없음 → 구현 결정 필요 |
