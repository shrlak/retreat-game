# 규칙 체크리스트 (원작 아발론 기준)

출처: 원작 레지스탕스 아발론 규칙서 기준. 사용자가 준 나무위키 문서는 이 환경에서 보안 확인(Cloudflare) 때문에 열지 못했음 → 나무위키 전용 항목은 열람 후 보강 필요.
열: **ID** / 규칙 / 엔진 구현 / 자동 테스트.
상태: ✅ 구현+테스트, ⚠️ 구현됐지만 원작과 다름/의심, ❌ 미구현.
