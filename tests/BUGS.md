- 엔진: 양쪽 다 서로 못 봄 (`hidesFromEvil`에 lancelotEvil 포함).
- 테스트는 지금 엔진 해석대로 검사하고(`expectedKnowledge(..., {official:false})`), 공식 해석은 `{official:true}`로 바꿀 수 있음. 어느 쪽으로 할지 결정 필요.

### #10 [규칙 차이] 충성 카드 덱 구성·시기
- 엔진: 5장(변화없음 3, 교체 2), 3번째 원정부터 매 라운드 1장(최대 3장 공개).
- 공식 변형 1: 6장(변화없음 4, 교체 2), 1번째 원정부터 매 원정 1장. 공식 변형 2: 7장 중 5장을 원정마다 미리 공개, 랜슬롯은 현재 진영대로 성공/실패 강제.
- 엔진 방식은 일부 커뮤니티 규칙과 비슷하지만 룰북과는 다름. 변형 2의 강제 카드는 미구현. 테스트는 엔진 방식(L4: 3번째 원정 전 공개 없음, 최대 3장, 교체 최대 2)으로 검사 중.

### #5 [확인 필요] web/net.js가 `Authorization` 헤더를 안 보냄

- Supabase Edge Function을 기본값(JWT 검증 켬)으로 배포하면 모든 요청이 401. `--no-verify-jwt`로 배포했다면 문제 없음. 실서버에서 확인 필요.
